# Guías de Andén

Las tres páginas se editan directamente en `servicios-de-pasajeros.html`, `traccion-ferroviaria.html` y `fotografia-ferroviaria.html`. Su diseño adicional está en `css/guias.css`; las tarjetas de acceso están en `index.html`.

Las fotografías originales permanecen en `images/`, con sus créditos y licencia. La fecha visible de cada artículo corresponde a su revisión editorial. No representa una fecha de captura de las fotos.

Para publicar, se conserva la estructura del sitio y el archivo `CNAME`. No hace falta compilación, Python ni un servidor propio. Las fuentes consultadas están enlazadas al pie de cada artículo.
